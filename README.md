# Velora

Velora is a small web-based OS i built myself using the Hack Club guide.

It includes just four apps: **Projects, Terminal, Settings, and Notes.** I wanted to keep things simple, without unnecessary apps or distractions, so Velora can feel like a little focus space.

## Features
- Draggable windows
- Terminal with basic commands
- Notes saved locally
- Light mode and window transparency settings
- Taskbar for switching between open apps
